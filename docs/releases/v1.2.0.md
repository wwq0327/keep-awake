# Keep Awake v1.2.0

## What's new

- Fix unsupported statistics values that could crash duration display, corrupt an in-memory total on overflow, or truncate large hour counts. Unreadable historical files remain preserved. (#1)
- Add **Retry shortcut** in alert details. After a shortcut conflict is resolved, registration can recover without interrupting the current session. (#2)
- Reduce repeated idle-state queries and unchanged menu bar title assignments. Allow a small timer tolerance while keeping durations and saves based on actual awake time. (#3)

## 更新内容

- 修复异常统计值可能导致的时长显示崩溃、累计溢出和超长小时数截断；继续保留无法读取的原始记录。对应 #1。
- 在提示详情中增加「重试快捷键」，解除冲突后即可恢复，无需重启或中断会话。对应 #2。
- 减少闲置状态的重复查询和菜单栏标题的无效赋值，为计时器增加少量调度容差；实际计时与保存口径不变。对应 #3。

## Verification / 验证

- 25 regression tests passed; release build completed with no warnings.
- Verified real Carbon shortcut conflict detection and retry in both on/off states. The real IOKit assertion stays unchanged during retry and is released on quit.
- Verified the extracted app bundle: code signature, arm64 architecture, macOS 13 deployment target, default-off startup, explicit-on assertion, second-instance rejection, popover positioning and Chinese/English previews.
- 没有对 CPU／电池节省幅度或过夜锁屏作新的验证结论。
