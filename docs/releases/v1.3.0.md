# Keep Awake v1.3.0

## 更新内容 / What's new

- 增加定时保持唤醒：选择不限时或自定义 00:01–24:00；到期后释放本应用的防闲置休眠断言。（#4）
- Add a timed keep-awake session with a configurable duration from 00:01 to 24:00. The app releases its idle-sleep assertion when time expires. (#4)

## 验证 / Verification

- `swift build`、`swift build -c release` 和 30 项回归测试通过。
- 真实 IOKit 断言在注入到期时间后释放，统计保存通过；解压后的应用签名、arm64 架构和 macOS 13 最低版本已核验。
- 菜单栏界面自动化超时；单击、双击及键盘编辑的实机交互尚未验收，本版本暂为草稿。
- Menu bar UI automation timed out; real click, double-click and keyboard editing remain to be verified. This release is a draft.
