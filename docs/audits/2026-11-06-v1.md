## 修复说明

### #1 安全统计数值

新增 `AwakeDuration`，用可失败的 Int64 转换检查数值，再以 64 位格式显示；无效值显示 `—`。小数秒仍保存在原有 Double 字段中，显示取整，不改变已有 JSON 结构和计时口径。

历史累计不支持时报告读取错误，并沿用原文件禁止覆盖规则。普通会话仍可继续保持和计时。累计增量与新总量先验证再修改内存；正常磁盘写失败仍保留已累计的内存值并重试。

### #2 快捷键重试

仅注册失败时显示「重试快捷键」。重试复用 HotKeyManager 的注销／注册过程，不调用 AppState.start，不重建计时器或改变电源开关。成功清除快捷键错误，失败保留提示；退出阶段不再注册。

新增详情原生截图，检查正常、三项错误、浅深色及重试成功后的内容。三项错误详情超过视口时可滚动查看。

### #3 常驻开销

闲置状态作为已采样的可观察状态。读取属性不再访问系统，每个 tick 最多调用一次输入闲置查询，保持开启时不查询。无效的闲置时间按灰色处理，避免误报绿色。

菜单栏标题仅在内容变化时赋值。逐秒时长仍更新；计时器添加 0.1 秒调度容差，保存依据依然是单调清醒时钟达到 60 秒。没有测量 CPU 或电池收益，不对节能幅度作结论。
