# keep-awake 图标与界面提案

2026-11-06。用户已选择图标 C + UI A，并进一步确认「圆形反色图标」；已接入现有程序。下文的三套对比图保留为原始提案，实际界面以应用源码及 `.build/qa/panel-*.png` 为准。

## 结论

推荐「图标 C 环形闪电 + UI A 原生轻面板」。延续当前闪电标识，把开关提到状态旁边，三项统计保留。图标、界面可独立组合。

本目录内的提案预览由独立的 SwiftUI / AppKit 设计脚本渲染，时长均为示意数据，按钮与开关为静态设计示意。程序中的图标和面板已接入真实状态、断言与热键。

## 图标对比

| 方案 | 造型 | 判断 | 取舍 |
| --- | --- | --- | --- |
| A 极昼 | 日出、地平线、三条光线 | 更有自己的视觉特征 | 也可能被理解为亮度功能 |
| B 续杯 | 热咖啡杯与托碟 | 亲切，保持清醒的含义直观 | 属于常见防休眠工具意象，独特性较弱 |

- 菜单栏在 18 × 18 pt 画板内绘制，主线宽 1.55 pt；设计脚本保留可缩放路径。
- 开启采用橙色和实心主体，关闭采用线框；绿色表示近期有输入，灰色表示闲置。绿、灰均未开启防休眠。
- 对比图包含浅／深菜单栏及应用图标示意。应用图标尚未打包为正式 `.icns`，当前应用也没有因此新增 Dock 项。

## UI 对比

| 方案 | 内容尺寸 | 信息顺序 | 主操作 | 适用情形 |
| --- | --- | --- | --- | --- |
| A 原生轻面板 | 320 × 296 pt | 标题与快捷键 → 状态／开关 → 三行统计 → 说明与退出 | 状态旁开关 | 高频随手开关，优先紧凑 |
| B 会话计时台 | 340 × 382 pt | 标题 → 状态 → 本次大计时 → 累计／运行 → 操作与说明 | 底部整行按钮 | 经常关心本次保持多久 |
| C 状态与数据分区 | 388 × 328 pt | 标题 → 左状态／右统计 → 操作 → 说明 | 底部按钮，退出独立 | 喜欢状态、统计分开阅读 |

三种 UI 都提供 `ui-*-on.png` 和 `ui-*-off.png`。关闭后显示「上次保持」，保留上一会话值；首次启动没有会话时正式接入应显示 `—`。B 的深色是视觉方向示意，正式接入仍需设计系统浅／深色适配。

## 正式接入时保留的边界

- 继续只阻止闲置系统休眠：允许锁屏和熄屏；手动睡眠、合盖及低电量仍可能休眠。
- 热键仍为 `⌃⌥⌘K`。退出或重启不自动恢复保持状态，显式启动参数行为沿用现状。
- 热键冲突、断言失败、统计保存失败仍须可见。预览展示正常路径，错误接入时使用统计下方的可滚动信息区域，并同步预先确定的 popover 尺寸；不得错误地显示成功状态。
- 保留「保持时长不计系统休眠时间」和「停止或退出只解除本工具限制」的详细说明入口，默认面板优先展示简短边界。
- 长时长不能截断：至少检查 `9999:59:59`、首次无数据，以及关闭后的上次会话。
- 沿用固定 `popover.contentSize` 和 hosting sizing 约束，正式接入后再验证真实菜单栏锚点、点击区域、VoiceOver 和键盘操作。
